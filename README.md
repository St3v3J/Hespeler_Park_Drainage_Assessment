# Hespeler_Park_Drainage_Assessment

This project is an advanced geomatics analysis of spring flood water drainage in Hespeler Park in Niverville, Manitoba in 2026. It uses QGIS, LiDAR-derived elevation data, hillshade interpretation, aerial imagery, GPS field observations, and R-based spatial analysis to identify and classify flood-prone areas in the park.

The goal of the project was to create a repeatable, low-cost flood-zone inventory workflow that could document drainage issues, compare problem areas, and record data for professional review and maintenance. Flood-prone areas were mapped as polygons and classified by severity and mitigation. Data can be edited and is recorded in a database for comparison over time. An application to transfer map data between people in the field so they can open it and edit it on a mobile device is the next part I am working on.

This repository is intended as a portfolio project for job applications in GIS, geomatics, municipal operations, public works, and related technical roles.
